# Emma's Vocab Vault

An interactive digital flashcard and active-recall web application designed for UK Independent School entrance preparation (14+ / Year 10 entry).

## Core Features
- **4-Part Vocab Format:** Definition in own words, realistic sentence context, synonyms, and antonyms.
- **Categorisation:** Filters words by **Literary Techniques** (*irony*, *satire*, *alliteration*), **British Idioms**, and **Academic & Reasoning**.
- **Offline Persistence:** Uses browser `localStorage` so any new words Emma adds during her study sessions are saved automatically on her device.
- **Mobile & Tablet Friendly:** Responsive design for quick drills on a phone or laptop.

## How to Deploy to GitHub Pages (Free)

1. Create a new repository on GitHub named `emma-vocab-vault`.
2. Push or upload `index.html`, `styles.css`, `app.js`, `words.json`, and `README.md` to the `main` branch.
3. In GitHub, navigate to **Settings** > **Pages**.
4. Under **Branch**, select `main` and root `/`, then click **Save**.
5. Your web app will be live within 1–2 minutes at:
   `https://<your-username>.github.io/emma-vocab-vault/`
